# Mobile-First Premium E-commerce Website Prompt

Design and generate a complete, modern, responsive e-commerce website for selling all categories of goods including electronics, fashion, groceries, beauty products, home appliances, books, furniture, sports equipment, and accessories.

The design should be **mobile-first**, with every screen optimized for smartphones before adapting seamlessly to tablets and desktops.

## Design Style

Create an elegant, premium interface inspired by the simplicity and refinement of modern Apple product design, while remaining completely original.

Design principles:

* Minimalist layout
* Clean white backgrounds with subtle gray accents
* Generous whitespace
* Rounded corners (12–20px)
* Soft shadows
* Glassmorphism only where appropriate
* Large, bold typography
* Smooth gradients used sparingly
* High-quality product imagery
* Modern SF Pro–style typography (or a similar clean sans-serif)
* Smooth micro-interactions and animations
* Consistent spacing based on an 8px grid
* Premium feel with excellent visual hierarchy

Use a neutral color palette:

* White
* Light gray
* Charcoal
* Black
* Subtle blue as the primary accent

Avoid visual clutter.

## Responsive Layout

Generate three responsive breakpoints:

* Mobile (primary design)
* Tablet
* Desktop

Ensure every component adapts perfectly to different screen sizes.
